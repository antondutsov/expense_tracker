# Expense Tracker

A command-line app to record expenses and see totals per category.

## Features
- Add and list expenses
- Totals per category
- Saves data to a JSON file

## Setup
    py -m venv .venv
    .venv\Scripts\Activate.ps1
    pip install -r requirements.txt

## Usage
    python main.py
